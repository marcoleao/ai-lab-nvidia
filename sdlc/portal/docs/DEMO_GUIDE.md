# Primeiro teste humano — planejamento

O domínio e os dados são escolhidos pelo usuário. O sistema não cria exemplos.

1. Abrir a prévia local e selecionar a persona de planejamento.
2. Criar seu Sistema, Projeto (escolhendo runtime), Épico, História e Tarefa. Usar o breadcrumb para voltar aos níveis anteriores.
3. Verificar Projeto AWAITING APPROVAL, Épico TO DO, História SPECIFICATION e Tarefa TO DO. Se desejar, aprovar o Projeto e depois o Épico como Product Owner/Admin.
4. Atualizar uma Tarefa para DOING e DONE; conferir o registro no histórico.
5. Abrir a História e explicar, sem auxílio, onde está e qual é a sequência do processo. A execução permanece NOT STARTED nesta entrega.
6. Recarregar a página e conferir a preservação dos itens/contexto. Avaliar também em janela de 768 px.

Registrar dúvidas, ações difíceis de encontrar, rótulos ambíguos e perda de contexto. Não há teste humano de agentes, pacotes ou QA/HML/PRD neste incremento. Os três ambientes estão NOT DEPLOYED. Integrações ausentes são informadas, não simuladas.
