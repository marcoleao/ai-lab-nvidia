# AI Local Lab v1.0.0

Primeira versão estável do laboratório local de IA isolado em uma distro WSL2 dedicada. O Windows mantém apenas a plataforma WSL e o driver NVIDIA; Docker e a stack de IA ficam no Linux.

## Incluído

- Bootstrap com um comando: `.\bootstrap.ps1`.
- Ollama 0.40.4, Open WebUI 0.11.4, Qdrant, AI Dev/PyTorch CUDA e JupyterLab.
- Configuração declarativa de modelos, versões, profiles, portas e persistência.
- CLI de operação, doctor, smoke tests e nuke protegido por confirmação/propriedade.
- Retomada de downloads, tratamento de HTTP 412 e espera de healthchecks.
- Secrets fortes, binds em localhost e arquivos de runtime no filesystem Linux.

## Validado na workstation

Windows 11, WSL2 e RTX 5000 Ada Laptop de 16 GB: bootstrap completo; cinco serviços healthy; quatro modelos instalados; doctor com 22 verificações e zero erros; inferência qwen3:14b com uso de VRAM; computação PyTorch CUDA; WebUI, Qdrant e Jupyter aprovados. Stop/start com estado preservado confirmado pelo usuário.

## Começar

```powershell
git clone https://github.com/marcoleao/ai-lab-nvidia.git
cd ai-lab-nvidia
.\bootstrap.ps1
```

Open WebUI: http://localhost:3000. Consulte o README para requisitos, reboot/elevação, comandos e remoção.

## Limitações

Modelos maiores não têm inferência automaticamente validada nesta GPU de 16 GB. Gemma3:27b não suporta ferramentas no Ollama instalado. O ciclo destrutivo nuke → bootstrap continua pendente de validação completa. A release não inclui modelos, secrets, dados de aplicação ou imagens Docker; esses artefatos são obtidos no bootstrap.
